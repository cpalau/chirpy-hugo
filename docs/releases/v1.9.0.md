# Chirpy Hugo v1.9.0

One new beyond-upstream switch: dates in the site's language in self-host
mode. **Off by default**: a site that does not set it renders the same HTML as
v1.8.0.

Tracks upstream `cotes2020/jekyll-theme-chirpy` **v7.6.0**.
Parity: Gate G4 ✅ (50/50 pages) · Gate G5 ⚠️ unchanged since v1.6.14 (see
[Parity status](#parity-status)).

## Highlights

- Dates can follow the site language in self-host mode
  (`params.assets.dayjs_locale`). Before, a Spanish site showed "Nov 1, 2026";
  with an `es` locale file it shows "1 de nov de 2026".

## Added

- **`params.assets.dayjs_locale`** (default `""`). The post meta, the home
  cards and the archives format dates in the browser with Day.js. The theme
  calls `dayjs.locale(<page language>)`, but in self-host mode it only ships
  `locale/en.js`, as upstream does. Any other language has nothing to load and
  Day.js silently falls back to English.

  The switch points to a locale file served by the site. `:LOCALE` is replaced
  by the language code, so a multilingual site serves one file per language:

  ```toml
  [params.assets]
    dayjs_locale = "/assets/js/dayjs/:LOCALE.js"
  ```

  Then copy `locale/<lang>.js` from the `dayjs` npm package (MIT, 1.11.x) to
  `static/assets/js/dayjs/<lang>.js`.
