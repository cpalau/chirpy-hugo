# chirpy-hugo v1.2.1

Two text-level fixes found by comparing the live demo with the original after
the SEO port.

## The `filepath` shortcode leaked a newline

`layouts/_shortcodes/filepath.html` ended with a newline, and an inline element
cannot afford one: the browser renders it as a space, so
`` `assets/img/favicons/` `` followed by a period became
`assets/img/favicons/ .` — in the body and, through the excerpt, in the meta
description.

The template now ends with a whitespace-trimming action, and the deployment
gate rejects the pattern (`</code>` followed by whitespace and punctuation) on
the demo, which is the only page that exercises it: Gate 4 canonicalises
whitespace and the fixtures never put punctuation right after an inline
shortcode.

## The description used `plainify`

`plainify` inserts a space where an inline tag was, so a description built from
an excerpt with inline code or a link could differ from Jekyll's
`strip_html`-based text. The excerpt is now stripped with the same rule
(remove tags, unescape entities, collapse whitespace) and cut to 100 words.

Measured after both fixes: the demo page and `chirpy.cotes.page` produce the
same description (`… assets/img/favicons/. You may …`), 50/50 pages remain
DOM-identical, 84/84 pixel pairs identical, and the SEO gate stays green
(2413 checks).

## Compatibility

No configuration or content changes. The fixes are internal to the theme.
