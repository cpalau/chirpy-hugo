# Chirpy Hugo v1.5.4

A packaging release: the theme now carries everything the Hugo theme gallery
reads, so it can be listed on <https://themes.gohugo.io>. No template,
stylesheet, script, locale or configuration default changed, so the rendered
site is byte-identical to v1.5.3.

Tracks upstream `cotes2020/jekyll-theme-chirpy` **v7.6.0**.
Parity: Gate G4 ✅ (50/50 pages) · Gate G5 ✅ (zero pixels outside the three
declared boxes).

## Highlights

- The theme is ready to be submitted to the Hugo theme gallery.
- The README mockup now loads on themes.gohugo.io, which renders the README
  from its own directory and cannot resolve relative image paths.
- `theme.toml` is complete for the gallery: the `[original]` block records the
  upstream repository as well as its author and homepage.

## Added

None.

## Changed

- **`theme.toml` records the upstream repository.** `[original]` gains
  `repo = "https://github.com/cotes2020/jekyll-theme-chirpy"`, the field the
  gallery uses to link a port back to the project it ports.
- **The README mockup uses an absolute URL.** It was `images/devices-mockup.png`;
  it is now the `raw.githubusercontent.com` URL, because themes.gohugo.io
  rewrites relative paths against its own directory and showed a broken image.
- **`AGENTS.md` §14.6 documents the current submission flow.** The old checklist
  described the retired `gohugoio/hugoThemes` repository (open an issue, prefix
  the repository with `hugo-theme-`). It now describes
  `gohugoio/hugoThemesSiteBuilder`: a pull request to `themes.txt`, metadata and
  images read from the latest release tag, absolute README image URLs, the
  18-month staleness rule and SemVer tags that must never be deleted.

- **G4 (HTML):** 50 pages, 50 identical, 0 with differences.
- **G5 (pixels):** the full matrix, 84 pairs, 0 differing pixels outside the
  declared D-02, D-09 and D-18 boxes.
- **G1, G2, G3, G9 and G10:** green (`npm run test:fast`).
- G6, G7 and G8 were not touched: no template, locale or asset changed.
