# Chirpy Hugo v1.7.0

Four new beyond-upstream switches for SEO, accessibility and search size. All
four are **off by default**: a site that does not enable them renders the same
HTML as v1.6.14.

Tracks upstream `cotes2020/jekyll-theme-chirpy` **v7.6.0**.
Parity: Gate G4 ✅ (50/50 pages) · Gate G5 ⚠️ unchanged from v1.6.14 (see
[Parity status](#parity-status)).

## Highlights

- Pinch-zoom can be enabled (`params.a11y.allow_zoom`). Upstream's viewport
  blocks it, which fails WCAG 1.4.4 (D-24).
- The JSON-LD image can be a valid schema.org `ImageObject`
  (`params.seo.image_object`).
- `search.json` can be capped per entry (`params.search.content_chars`). On a
  100-post archive the full-text index weighed 2 MB.

## Added

- **`params.seo.image_object`** (default `false`). jekyll-seo-tag emits
  `"@type":"imageObject"` with `alt` and `lqip`. schema.org types are
  case-sensitive and `ImageObject` has neither property. With the switch on,
  the type is `ImageObject`, `alt` becomes `caption` and the base64 `lqip`
  placeholder is dropped.

  ```toml
  [params.seo]
    image_object = true
  ```

- **`params.seo.noindex_404`** (default `false`). Adds
  `<meta name="robots" content="noindex, follow">` to the 404 page, which is
  otherwise indexable under `/404.html`.
- **`params.a11y.allow_zoom`** (default `false`). Removes
  `user-scalable=no` from the viewport and keeps the other directives:
  `width=device-width, initial-scale=1, shrink-to-fit=no, viewport-fit=cover`.

  ```toml
  [params.a11y]
    allow_zoom = true
  ```

- **`params.search.content_chars`** (default `0`, the full text as upstream).
  A positive value caps each `search.json` entry at that many characters, cut
  at a word boundary and never inside a character reference. It trades recall
  for size: a match beyond the cap no longer finds the post.

  ```toml
  [params.search]
    content_chars = 500
  ```

## Changed

- The standards gate (`tests/seo/check.mjs`) accepts both `imageObject`
  (upstream) and `ImageObject` (opt-in) as the JSON-LD image type.

## Fixed

None.

## Breaking changes

None. All new keys default to the upstream behaviour.

## Upstream sync

Still tracking Chirpy **v7.6.0**. Nothing was ported. D-24 (viewport) now
documents the opt-out; no other `D-xx` changed.

## Parity status

Measured on this commit with Hugo 0.169.0 extended against the Jekyll oracle:

- **G4 (HTML):** 50 pages, 50 identical, 0 with differences.
- **Full suite (`npm run test:all`):** all 18 gates green, including Gate 4c
  (SEO extensions, 53 checks, with one assertion per new switch), a11y, LCP and
  Lighthouse.
- **G5 (pixels):** 18 of 18 pairs differ outside the declared boxes. **This
  is not introduced by this release:** v1.6.14 produces the same 18 failures
  with the same pixel counts, measured side by side on the same machine. The
  regression predates this release and is tracked separately. The new switches
  are off in the visual fixture, so they cannot affect it.

## Upgrade

```bash
hugo mod get -u github.com/cpalau/chirpy-hugo@v1.7.0
```

No manual step is required. To opt in, add the keys above to your site
configuration.
