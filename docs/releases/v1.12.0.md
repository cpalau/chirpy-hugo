# Chirpy Hugo v1.12.0

An opt-in that gives the icon-only controls an accessible name.

Tracks upstream `cotes2020/jekyll-theme-chirpy` **v7.6.0**.
Parity: Gate G4 ✅ · Gate G5 ✅ (defaults unchanged).

## Highlights

- `params.a11y.control_names`: the table-of-contents button and the heading
  anchors get an accessible name. On a real site, Lighthouse accessibility goes
  from 92 to 100 on a post and from 96 to 100 on a page with sections.

## Added

- **`params.a11y.control_names`** (B25, `false` by default).
  - The icon-only TOC button in the top bar is named with the `panel.toc`
    label ("Contents", "Contenido").
  - Each heading anchor is named with its heading text (escaped). No new
    translation string: the catalogue stays generated from upstream, and it
    works in every language.
  - Upstream leaves both nameless: axe `button-name` and `link-name` fail
    (WCAG 2.4.4 and 4.1.2).

## Changed

None. With the option off, the HTML is byte-identical to v1.11.1.

None.

## Parity status

Measured on this commit with Hugo 0.169.0 extended against the Jekyll oracle;
`npm run test:all` green, including Gate 4c with three new checks (named TOC
button, named anchors, escaped heading text) and the i18n gate.

## Upgrade

```bash
hugo mod get -u github.com/cpalau/chirpy-hugo@v1.12.0
```

```toml
[params.a11y]
  control_names = true
```
