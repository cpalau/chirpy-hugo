# Chirpy Hugo v1.8.0

Two new beyond-upstream switches for tag and category pages. Both are **off by
default**: a site that does not set them renders the same HTML as v1.7.0.

Tracks upstream `cotes2020/jekyll-theme-chirpy` **v7.6.0**.
Parity: Gate G4 ✅ (50/50 pages) · Gate G5 ⚠️ unchanged since v1.6.14 (see
[Parity status](#parity-status)).

## Highlights

- Term pages can have their own meta description without writing an
  `_index.md` for each one (`params.seo.term_description`).
- Term pages can have a descriptive `<title>` instead of the bare term
  (`params.seo.term_title`), while the visible H1 stays as it is.

## Added

- **`params.seo.term_description`** (default `""`). Upstream falls back to the
  site description on every tag and category page, so a site with 90 tags
  ships 90 identical meta descriptions. The template applies to term pages
  without their own `description`; `{term}` is the term as the page shows it.
  A term with an `_index.md` description keeps its own text.

  ```toml
  [params.seo]
    term_description = "Posts about {term}: practical guides with code examples."
  ```

- **`params.seo.term_title`** (default `""`). A template for the `<title>`,
  `og:title`, `twitter:title` and JSON-LD headline of term pages. The H1 is not
  affected, so the DOM contract and parity are unchanged.

  ```toml
  [params.seo]
    term_title = "Posts about {term}"
  ```

## Changed

- The SEO title is computed in a new partial, `seo/page-title.html`, shared by
  `head.html` and `seo.html`. With the switches off it returns exactly
  `display-title.html`.
