# chirpy-hugo v1.5.1

One small feature: the footer line is now site-owned.

## `params.footer.copyright`

The footer used to hard-code the upstream line:

```html
© 2026 Cristian Palau. Some rights reserved.
```

A site can now replace it with a single parameter:

```toml
[params.footer]
  copyright = "Made with ❤️ by :author"
```

- `:author` becomes `params.social.name`, linked to the first entry of
  `params.social.links` when there is one;
- `:year` becomes the current year;
- an empty value keeps the upstream line, so existing sites and the parity
  fixtures are unchanged.

The demo uses `Made with ❤️ by :author`, which renders as
`Made with ❤️ by Cristian Palau` with the name linked to the project.

The second footer line (the Hugo and theme credit) is untouched; the theme
release in its tooltip still comes from `data/theme.yaml`.

## Tests

The adoption feature matrix builds a site with the parameter and asserts the
custom line appears and the upstream copyright does not. The parity corpus is
unaffected because the default is empty.

Measured: 50/50 DOM, 84/84 pixels, 47 plugin checks, zero warnings.
