# Chirpy Hugo v1.10.0

An accessibility release: one parity fix that removes a critical axe
violation, one opt-in switch, a language-neutral heading, and code comments
in English.

Tracks upstream `cotes2020/jekyll-theme-chirpy` **v7.6.0**.
Parity: Gate G4 ✅ (50/50 pages) · Gate G5 ⚠️ unchanged since v1.6.14 (see
[Parity status](#parity-status)).

## Highlights

- Markdown task lists (`- [x]`) now look like upstream on Hugo and no longer
  ship unlabelled checkboxes.
- Previous/next post links can carry the post title in their accessible name
  (`params.a11y.post_nav_titles`).

## Added

- **`params.a11y.post_nav_titles`** (default `false`). Upstream names each
  post navigation link only "Previous" or "Next" while it shows the post
  title. The accessible name does not contain the visible text (WCAG 2.5.3,
  axe `label-content-name-mismatch`), so a voice-control user who reads the
  title out loud cannot activate it. With the switch on, the name is
  "Previous: <title>".

  ```toml
  [params.a11y]
    post_nav_titles = true
  ```

## Changed

- **Hidden home heading.** From page 2 on, the visually hidden `h1` of the
  home listing read "<site> — página N", hard-coded Spanish in a public theme.
  It now reads "<site> — N/total", which works in any language and stays
  unique per page.
- **Template comments** are written in English (R5). The rendered HTML does
  not change.

## Fixed

- **Goldmark task lists.** Symptom: on a Hugo site, `- [x]` items kept their
  bullets and showed bare disabled checkboxes; axe reported each one as an
  unlabelled form control (`label`, critical). Cause: `content.html` replaced
  the checkbox only in kramdown's markup (`class="task-list-item-checkbox"`),
  which Goldmark never emits. Fix: Goldmark items now get `task-list-item`,
  their list `task-list`, and the upstream check/circle icons, so the existing
  SCSS styles them exactly as Chirpy does.

## Breaking changes

None. The task list change makes the output match upstream; the post nav
switch is opt-in.

## Upstream sync

Still tracking Chirpy **v7.6.0**. Nothing was ported. D-20 (inherited
accessibility debt) now points to the post nav opt-out.

## Parity status

Measured on this commit with Hugo 0.169.0 extended against the Jekyll oracle:

- **G4 (HTML):** 50 pages, 50 identical, 0 with differences.
- **Full suite (`npm run test:all`):** all 18 gates green, including Gate 4c
  (68 checks, with a Goldmark task list fixture) and the a11y gate.
- **G5 (pixels):** the 18 pre-existing differences reported in v1.7.0 remain;
  they date from v1.6.14 or earlier.

## Upgrade

```bash
hugo mod get -u github.com/cpalau/chirpy-hugo@v1.10.0
```

No manual step is required.
