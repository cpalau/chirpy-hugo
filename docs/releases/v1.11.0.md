# Chirpy Hugo v1.11.0

Pixel parity is back. The visual gate (G5) had been failing on all 18 pairs
since v1.6.x without anyone noticing, because `npm run test:all` did not run
it. This release fixes both causes and adds G5 to `test:all`.

Tracks upstream `cotes2020/jekyll-theme-chirpy` **v7.6.0**.
Parity: Gate G4 ✅ (50/50 pages) · Gate G5 ✅ (18/18 pairs, zero pixels
outside the declared D-02, D-09 and D-18 boxes).

## Highlights

- The home page no longer shows a stray large site title above the post
  cards.
- Every page is pixel-identical to the Jekyll original again, and the gate
  that proves it now blocks a push.

## Added

- **`params.performance.content_visibility`** (default `false`). Applies
  `content-visibility:auto` to article blocks below the fold, which speeds up
  the first paint of long posts on slow CPUs. It was on by default since
  v1.6.x; see Changed.

  ```toml
  [params.performance]
    content_visibility = true
  ```

## Changed

- **`content-visibility:auto` is opt-in.** With it, the browser paints the
  deferred blocks in their own layers: text antialiasing changes and, through
  `contain-intrinsic-size`, an inline image grew by 8 px, so every post failed
  G5. Without it the fixture still scores 93–94 on mobile (Jekyll: 66–72),
  within the Lighthouse budgets. Sites that relied on it set the parameter
  above.
- **`npm run test:all` runs the visual gate.** The pre-push hook therefore
  rejects any pixel regression.

## Fixed

- **Visible listing title.** Symptom: since v1.6.x the home page showed the
  site title as a large heading above the first card. Cause: the listing `h1`
  uses `class="visually-hidden"`, but the purged Bootstrap shipped with the
  theme does not contain that rule, because upstream never uses it. Fix: the
  theme inlines Bootstrap's `.visually-hidden` rule.

## Breaking changes

None for the markup or the configuration. Sites that want to keep the
below-the-fold `content-visibility` must now set
`params.performance.content_visibility = true`.

## Upstream sync

Still tracking Chirpy **v7.6.0**. Nothing was ported. D-28 documents the new
opt-in and the hidden `h1` rule.

## Parity status

Measured on this commit with Hugo 0.169.0 extended against the Jekyll oracle:

- **G4 (HTML):** 50 pages, 50 identical, 0 with differences.
- **G5 (pixels):** 18 pairs, 18 pixel-identical outside the declared boxes.
- **Full suite (`npm run test:all`, now including G5):** all gates green.

## Upgrade

```bash
hugo mod get -u github.com/cpalau/chirpy-hugo@v1.11.0
```

Set `params.performance.content_visibility = true` to keep the previous
render path on long posts.
