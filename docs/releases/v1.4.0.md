# chirpy-hugo v1.4.0

A second round of SEO additions, this time from the current Google
documentation rather than the Jekyll original. All are off by default; the
parity gates are unchanged (50/50 DOM, 84/84 pixels).

## 1. Google Discover: `max-image-preview:large`

Discover's documentation still requires `max-image-preview:large` (or AMP) for
large thumbnails. The theme now emits it when the site sets it:

```toml
[params.seo]
  max_image_preview = "large"   # or "standard", "none"
```

It is merged with `noindex` into one tag, so a hidden post can be both:

```html
<meta name="robots" content="noindex, follow, max-image-preview:large">
```

## 2. Image sitemap

Google still recommends an image sitemap for images it may not discover on its
own. With `params.seo.image_sitemap = true`, every post cover is listed with the
protocol extension, and the `urlset` declares the namespace:

```xml
<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9"
        xmlns:image="http://www.google.com/schemas/sitemap-image/1.1" …>
  <url>
    <loc>https://example.com/posts/hello/</loc>
    <image:image><image:loc>https://example.com/img/cover.png</image:loc></image:image>
  </url>
</urlset>
```

A multilingual site already publishes one sitemap per language plus an index;
the entries follow.

## 3. `llms.txt`

`llms.txt` is an emerging convention for AI agents, and Lighthouse 12 audits for
it. The theme ships `layouts/llms.txt` but Hugo only renders it when the home
page lists the format, so it costs nothing until a site opts in:

```toml
[outputs]
  home = ["HTML", "feed", "search", "swconf", "manifest", "llms"]
```

The output is the site title, the site description, and a link list of posts and
pages — hidden posts and `noindex` pages excluded.

## 4. `og:locale:alternate`

Every translated page now lists the locales of its siblings, which is what the
Open Graph protocol defines for localized objects. It renders only when a page
has translations, so monolingual sites are unchanged.

## 5. Tests

Gate 4c (`npm run test:seo:ext`) grew to 44 checks. It now asserts, on the
multilingual fixture with every switch on:

- `og:locale:alternate` lists the other languages and not the page's own;
- the combined `robots` meta holds `noindex`, `follow` and
  `max-image-preview:large` together, and a normal post is Discover-ready;
- the sitemap declares the image namespace and lists the cover;
- `llms.txt` has the site summary, a post link, and no hidden or `noindex`
  content.

The standards gate then validates the whole build.

Measured: 50/50 DOM, 84/84 pixels, 3941 SEO checks, 197 demo standards, 44
extension checks, zero warnings.
