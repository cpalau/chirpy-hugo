## About this site

This is the demo of **chirpy-hugo**, a Hugo port of the Jekyll theme Chirpy.
It exists to show the theme with neutral content; a real site replaces it.

The theme keeps the upstream stylesheet and JavaScript byte-for-byte identical,
so the markup has to match the Jekyll original. That is measured, not claimed:
the repository ships a Jekyll oracle and a pixel comparison against it.
