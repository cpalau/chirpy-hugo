{{- /* Hugo normalises taxonomy keys (lowercase, diacritics kept), but upstream keeps the string written in the front matter. This returns a map {normalised key: original label} built from the pages, so both the label and the slug can be rendered exactly like Jekyll. One map per taxonomy, as Jekyll keeps `site.tags` and `site.categories` apart: with a single map, a tag `seo` and a category `SEO` shared one key and the category page showed the tag's lowercase label. Context: dict "page" (any page) "taxonomy" ("tags" or "categories"). Returns a dict. */ -}} {{- $taxonomy := .taxonomy -}} {{- $labels := dict -}} {{- range .page.Site.RegularPages -}} {{- range index .Params $taxonomy -}} {{- $key := lower . -}} {{- if not (index $labels $key) }}{{ $labels = merge $labels (dict $key .) }}{{ end -}} {{- end -}} {{- end -}} {{- return $labels -}}
