{{- /* Jekyll's `strip_html`, which runs on HTML that already has newlines between blocks. Hugo's `plainify` concatenates them ("IntroductionThis"), losing word boundaries and breaking both the read-time count and the search index. Block boundaries become a space; inline tags are removed without one, exactly like kramdown's output. Returns a string. */ -}} {{- $s := printf "%s" . -}} {{- /* Jekyll's strip_html removes comments and script/style blocks whole, not just their tags; a commented-out code gutter must not add words. */ -}} {{- $s = replaceRE `(?s)` "" $s -}} {{- $s = replaceRE `(?s)` "" $s -}} {{- $s = replaceRE `(?s)` "" $s -}} {{- $s = replaceRE `` " " $s -}} {{- $s = replaceRE `` " " $s -}} {{- $s = replaceRE `<[^>]+>` "" $s -}} {{- $s = htmlUnescape $s -}} {{- return ($s | replaceRE `\s+` " " | strings.TrimSpace) -}}
